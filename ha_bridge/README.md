# HA Bridge

在 Home Assistant 中直接运行 HA Bridge 智能家居可视化面板。

## 访问地址

启动 Add-on 后，在浏览器中打开：

```text
http://Home Assistant_IP:18080
```

## 相关链接

[官方网站](https://wiki.habridge.cn/) · [使用说明](https://wiki.habridge.cn/manual/first-setup.html)

## 数据保存

- `/data`：数据库、项目、素材、授权状态、Home Assistant 链接及本地账号
- `/run/secrets`：本地安全信息

升级或重启 Add-on 不会清除以上数据。
